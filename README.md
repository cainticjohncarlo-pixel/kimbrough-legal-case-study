# Kimbrough Legal Intake — Case Study Page

A single-file static HTML case study for the Kimbrough Legal Intake and Case
Management project. Used as a portfolio / presentation page.

- **`index.html`** — the complete case study page. No build step, no dependencies.
- Deploys as a static site (e.g. on Vercel) with zero configuration.

The project this describes lives at:
https://github.com/cainticjohncarlo-pixel/kimbrough-legal-intake

## Preview locally
Just open `index.html` in any browser, or serve the folder:
```
python -m http.server 8000
```
then visit http://localhost:8000
